## 🧭 ¿Qué es?

**The Green Garden Menu** es un menú digital interactivo con gamificación para bares y restaurantes. Incluye una ruleta de premios que sorprende a los clientes mientras exploran la carta de tragos y cocktails.

🔗 **Live:** [the-green-garden-menu.vercel.app](https://the-green-garden-menu.vercel.app)
